# PDF 文本提取与分块

## 责任

`yanbao/extractor.py`：把本地 PDF 变成可以入库的文本块——读取页面文本、清洗、并在长度受控的前提下切块。

## 边界

只依赖配置（块大小与重叠参数）与 pypdf。**不访问数据库、不做向量化、不关心研报元数据**：它面对的是一个 PDF 路径，交出的是一组 `(块文本, 长度)`。

## 决策与不变量

- **块长度是硬上限**：`CHUNK_SIZE`（默认 512 字符）同时是字符上限与嵌入模型的 token 上限对应的安全值。超长段落先在换行/句读处切分，实在断不开才硬切——任何输入下都不允许产出超长块。历史上旧切块器没有这条约束，导致绝大多数块超过模型上限、向量在截断文本上算出，语义检索结果不可信。
- **重叠服务于检索连续性**：块之间保留 `CHUNK_OVERLAP` 字符的重叠，重叠片段必须放得进下一个块（否则丢弃），避免答案正好落在切口上。
- **抽取失败不抛异常**：文件缺失、解析异常、无可抽取文本，一律返回 `(None, 错误说明, 页数)`，由调用方决定是标记损坏还是重试。抽取路径不允许把异常抛回管线。
- **页数是处理判据**：页数一并返回，索引管线据此判断某篇是否已处理过。
