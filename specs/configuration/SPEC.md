# 配置与环境变量

## 责任

`yanbao/config.py`：全项目唯一的配置来源——从进程环境变量与仓库根目录的 `.env` 读取全部可调参数，并提供默认值。

## 边界

只被读取，**不含任何业务逻辑**。模块导入时被求值，因此配置在进程内是常量快照。

## 决策与不变量

- **优先级固定**：进程环境变量 > `.env` 文件 > 代码默认值。`.env` 只补齐环境里没有的键。
- **结构性常量也在此定义**：向量维度、因子类型集合、向量表名等不随部署环境变化的量集中在此，避免散落各处造成不一致。
- **默认值要能直接跑通**：默认数据目录、库路径、嵌入模型名、块大小与重叠、状态文件与损坏 PDF 台账路径、日志级别、LLM 端点与超时，均有内置默认值，未配置 `.env` 也能启动。
