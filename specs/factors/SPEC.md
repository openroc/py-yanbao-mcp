# 结构化因子提取

## 责任

`yanbao/factor_extractor.py`：从研报文本中抽取结构化的驱动因子——类型、名称、数值、单位与原文出处。

## 边界

允许依赖配置（因子类型集合）与 LLM 客户端（仅 LLM 提取路径使用）。**不访问数据库**：抽到什么由 [indexing] 负责落库，因子怎么查由 [retrieval] 负责。

## 决策与不变量

- **因子类型是封闭集合**：产能、订单、报价、增速、政策、成本、库存、销量。集合外的类型一律丢弃，不归入「其他」类；集合的变更意味着数据契约变更。
- **主路径是规则提取**：正则匹配「数值 + 单位 + 关键字」组合，零外部依赖、结果可重复、速度快。索引管线当前固定走规则提取。
- **LLM 提取是备选能力，不是自动路径**：模块里保留了基于 LLM 的提取函数与专用提示词，但没有任何命令或管线阶段触发它；LLM 失败时该函数自身降级回规则提取。启用 LLM 并不会让索引改用 LLM 提取（原文 USAGE.md 曾如此描述，已更正）。
- **只保留有数值的事实**：无数值的条目丢弃；数值大于等于 1e10 视为异常数据丢弃。
- **规则提取的产物形态固定**：因子名统一为「<类型>相关」，单位取自匹配模式，出处为命中的原文行。

## 相关
