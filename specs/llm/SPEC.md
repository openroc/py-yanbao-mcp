# LLM 客户端与研报问答

## 责任

`yanbao/llm.py`：对接 OpenAI 兼容的 LLM 端点（默认本机 `llama-server`），提供三种能力——研报问答（单问单答）、单篇摘要、多研报综合分析。

## 边界

允许依赖检索（取上下文）与配置（端点、模型、超时、密钥）。**LLM 服务本身不属于本项目**，是外部可选进程；本模块不落库、不管理模型。

## 决策与不变量

- **未启用即明确报错**：`YANBAO_LLM_ENABLED` 关闭时，调用这些能力的入口抛出「LLM 功能未启用」，由 CLI / MCP 转成友好提示。库与检索能力不受影响。
- **上下文以语义检索为骨干，并补齐同标的最近研报**：先做语义检索，再取命中标的的最新几篇研报补入上下文，最后按报告日期倒序排列，保证时效性优先。
- **回答必须可追溯**：上下文按编号编段，提示词要求标注来源编号；信息不足时要求如实说明，而不是编造。
- **客户端复用并显式关闭**：每次能力调用创建一个 `LLMClient`，内部复用单个 HTTP 客户端，调用结束后关闭。
- **文本有上限**：送给模型的研究报正文按长度截断，避免超长上下文。
